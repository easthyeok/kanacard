# 스테이지 확장 분석과 구현 기록

## 기존 구조 분석

- `core.js`: DOM 없는 규칙 엔진. 8층 경로, 전투당 덱 섞기, 한 턴 한 장, 정답 100%/오답 50%, 방어·회복·다음 공격 준비, 엘리트와 8층 보스, 보상·휴식·이벤트를 관리했습니다.
- `app.js`: 네 캐릭터 선택, 다섯 학습 단계, 문자 범위와 묶음 길이, 퀴즈·해설·일본어 음성, 카드 도감과 다음 탐험 시작 카드, 영구 경험치, 자동 저장과 UI를 연결합니다.
- `lessons.js`: 히라가나/가타카나 46자, 한글 발음 선택지, 단어·기본 표현·상황별 회화. 문자 가방을 모두 소진한 뒤 다시 섞습니다. 이번 변경에서도 출제 구조를 유지했습니다.
- `portraits.js`, `combat-actor.js`, `monsters.js`: 캐릭터 초상, 관절 애니메이션, 로컬 몬스터 SVG. `word-effects.js`는 배운 글자를 캔버스로 발사합니다.
- `style.css`, `viewport.js`: 모바일 세로와 작은 가로 화면, 터치 손패, 시각 뷰포트·안전 여백, 가로 전체 축소 배치.
- `pwa.js`, `sw.js`: 설치·선택적 업데이트·경로별 오프라인 캐시. GitHub Pages 정적 배포.

## 구현 계획과 변경 경계

1. 카드·적·노드·보상·지역 수치와 테마를 `world-config.js`로 분리했습니다.
2. 새로운 탐험 규칙을 `world.js`에 구현하고 기존 엔진에는 world 상태가 있을 때만 호출되는 연결 지점을 추가했습니다.
3. `world-view.js`에 월드맵·노드·비전투 화면, `world-art.js`에 지역별 전장, `music.js`에 사용자 선택형 합성 BGM을 구현했습니다.
4. 기존 화면·저장·학습 통계와 연결했습니다. 캐릭터 성장, 도감, 글자 공격, 한 턴 한 장을 유지합니다.
5. 저장 JSON, 새 규칙, 기존 8층 규칙, 모바일 화면 전환, 오프라인 자산을 검증했습니다.

## 새 탐험

6지역 × 지역당 6목적지 = 36개 목적지. 학습 단계와 지역은 별개이므로 같은 히라가나 설정으로 모든 지역을 탐험할 수 있습니다.

지역 내 경로는 입구 전투 → 전투/정예/학습 → 생존/연속/수호자 → 상점/이벤트/보물 → 휴식/이벤트 → 보스의 6개 열입니다. 노드 배치와 연결이 시드에 따라 달라집니다. 직전 노드에 연결된 다음 열만 선택할 수 있고, 지도·상점 재진입으로 다시 추첨되지 않습니다. 지도 전체를 먼저 살펴보고 위험·보상에 따라 분기를 선택합니다.

- 생존: 적을 처치하거나 설정된 4회 적 행동을 살아남으면 보상. 체력 0이면 패배를 우선 판정합니다.
- 연속: 3연전. 중간 체력 회복과 추가 보상 없이 다음 적으로 전환하고 소멸 카드를 유지합니다. 완료 보상에서 유물 회복 효과를 적용할 수 있습니다.
- 수호자: 강화된 정예와 희귀 카드 보상.
- 보스: 지역별 행동 순서, 체력 50% 이하 2페이즈의 순서 역전과 강화. 보스 처치마다 유물, 금화, 희귀 카드 선택, 다음 지역 진입 회복을 제공합니다.
- 상점: 카드·회복약·무작위 유물. 잔액/체력/판매 상태를 검사하며 중복 구매를 막습니다.
- 휴식: 체력 회복 또는 카드 종류 강화. 같은 종류 전체에 최대 2회 적용하며, 학습 도감의 기본 카드 정보는 영구적으로 바꾸지 않습니다.
- 이벤트: 여행자·제단·샘물의 저장된 선택지. 비용과 결과를 미리 표시하고 지나갈 수 있습니다.
- 학습: 기존 출제기를 재사용하는 3문제 도전. 정답마다 금화, 모두 정답이면 추가 금화와 유물. 해설과 영구 학습 통계·경험치에 반영합니다.

유물 6종은 턴 방어, 정답 공격, 전투 후 회복, 첫 턴 카드, 금화, 다음 공격 준비를 지원합니다. 물/얼음 → 번개, 자연 → 꽃/종이의 카드 속성 시너지가 있습니다. **몬스터의 특정 일본어 문자나 행 약점은 없습니다.**

## 저장 호환성

기존 localStorage 키를 유지합니다. 기존 `version:2` 탐험은 8층 규칙 그대로 완료할 수 있으며, 퀴즈와 해설 상태도 유지합니다. 새 탐험만 `version:3` + `world.version:1`입니다. 새 탐험 교체는 기존 확인 화면을 사용합니다. 학습 진도·범위·묶음 길이·캐릭터 경험치·도감·시작 카드 선택은 초기화하지 않습니다.

새 저장에는 지역, 단계, 방문 노드, 전체 분기 지도, 난수 상태, 금화, 유물, 강화, 상점 판매 상태, 현재 특수 전투, 학습 도전 질문과 결과가 포함됩니다. 보상/구매/질문 제출은 phase와 완료 플래그로 중복 실행을 막습니다. 유효하지 않은 새 저장은 실행하지 않으며, 기존 값은 새 탐험을 저장하기 전까지 localStorage에 남습니다.

## 화면과 오디오

여섯 배경은 숲·도리이·등불 마을·설산·요괴성·책장으로 구분했습니다. 지역 진입과 보스 등장 연출, 진행도, 위험 표시, 보상과 유물 설명을 추가했습니다. `BGM`은 기본 OFF이며 켜면 지역별 음계·템포의 짧은 앰비언트 루프를 합성합니다. 탭이 숨겨지면 멈춥니다. 별도 서버·유료 API·외부 음원 요청은 없습니다.

사용자의 후속 요청에 따라 카드 UI는 확대 미리보기 이전 버전으로 되돌렸습니다. 세로에서도 카드 설명을 손패에서 읽고 직접 선택합니다. 캐릭터는 작게 유지하며, 세로 전투의 520px 제한을 해제해 화면 아래 빈 공간을 줄였습니다. 가로 축소 배치를 유지하며 비전투 화면으로 이동할 때 축소 상태를 해제합니다. 전투의 임시 글자 발사 테스트 버튼은 제거해 조작 공간을 확보했습니다.

## 검증과 한계

`tests/game.cjs`, `app.cjs`, `world.cjs`, `word-effects.cjs`, `pwa.cjs`, `music.cjs`를 사용합니다. 기존 전투/학습/저장, 분기 및 저장 복원, 36목적지/6보스, 생존·연속·희귀 보상, 상점 비용/중복, 강화, 유물/시너지, 학습 통계, 지역 UI, 오디오 재생 제어, 오프라인 파일 포함을 검증합니다.

40개 시드에서 기본 잉크 기사, 전부 정답, 안전 경로와 회복/강화를 선택하는 간단한 자동 정책은 40회 완료했고 평균 플레이어 행동은 약 69회였습니다. 이는 실제 사용자 승률이나 모든 캐릭터의 균형 검증은 아닙니다. 수치는 `world-config.js`에서 후속 조정할 수 있습니다.

이 환경에는 브라우저 제어 도구가 없어 실제 휴대폰 렌더링·설치·오디오 청취는 미검증입니다. 배포 후 세로/가로 회전, 긴 카드 설명, 학습 도전 재실행, 지역별 보스 페이즈를 실제 기기에서 확인해야 합니다.

추가 개선 후보: 더 다양한 이벤트와 지역 전용 카드, 플레이 기록에 따른 난이도 선택, 실제 플레이 통계 기반 보상·적 공격력 조정, 수작업 음원과 접근성 설정 확장.
