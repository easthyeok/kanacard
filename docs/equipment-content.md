# 장비·콘텐츠 확장 구현 기록

## 분석과 변경 경계

이전 소스는 `core.js`의 한 턴 한 장 전투, `world.js`의 6지역 분기/특수 전투, `world-config.js`의 밸런스, `world-view.js`의 비전투 UI, `app.js`의 학습·저장 연결로 구성되어 있습니다. 캐릭터 성장·카드 도감은 영구 저장되며 유물은 이미 탐험에만 들어 있습니다. SVG는 무기·팔·몸통 그룹을 분리해 애니메이션합니다.

전체 재작성 대신 장비를 독립 데이터/규칙/화면 모듈로 추가하고, 기존 전투의 시작·정답 효과·피해 처리 지점에 연결했습니다. 학습 데이터와 출제 방식은 유지합니다. 사용자 후속 지시에 따라 다중 몬스터·대상 선택·광역 대상 처리는 구현하지 않았습니다. 한 마리 전투, 무한 탑 없음, 문자/행 약점 없음으로 유지합니다.

## 단계별 구현

### 1. 장비와 저장

- `gear-config.js`: 3슬롯, 5등급, 능력치 범위·옵션 수·강화 비용·드롭·세트 설정.
- `gear.js`: 영구 인벤토리, 캐릭터별 장착 참조, 장비 비교, ID 발급, 저장 정리, 전투 적용.
- `gear-view.js`: 장비창·상세·강화 비교·세트 상태·정렬·등급 필터·24개 페이지.
- 무기/방어구/장신구 슬롯, 일반/고급/희귀/전설/신화 색상.
- 장비 하나는 동시에 한 캐릭터만 장착합니다. 장착 중 판매/분해를 막습니다.
- 전투·퀴즈 중 교체·강화를 막고 장비 능력치를 스냅샷으로 저장합니다. 장착 체력은 중복 가산하지 않으며 교체만으로 체력을 회복할 수 없습니다.

### 2. 파밍과 강화

- 일반/정예/수호자/보스/비밀 보스/보물/이벤트별 드롭률과 등급 가중치.
- 슬라임·달팽이·나무·버섯 등 몬스터에 따른 드롭 확률과 슬롯 비중.
- 6지역 장비 이름과 지역 세트. 보스 전용 이름/기본 능력 보너스 및 첫 보스 전설 보상.
- 상점에서 탐험 금화로 영구 장비를 구매합니다. 장비 판매와 처치에서 받는 **장비 골드**는 영구 강화에 사용하며, 기존 **탐험 금화**와 별개입니다.
- 전투/보스/이벤트/분해로 강화 재료 획득. +0~+10, 실패/파괴 없이 비용을 낸 뒤 단계가 증가합니다.
- 숲 2세트 턴 방어/3세트 시작 보호막, 요괴 2세트 공격/3세트 정답 추가 피해, 천공 2세트 체력/3세트 3연속 정답 드로우.
- 장비 능력치 상한과 옵션 개수로 덱의 역할을 보호합니다. 장비 공격·치명타·추가 공격·정답 회복은 정답에만 적용합니다.

### 3. 스테이지와 이벤트

`content-config.js`가 6개 지도 구조와 12개 이벤트, 비밀 보스 조건, 보스 패턴을 관리합니다.

| 지역 | 목적지 수 | 주된 변화 |
|---|---:|---|
| 시작의 숲 | 6 | 기본 전투·정령·무기고 |
| 안개 낀 신사 | 7 | 이벤트·생존·봉인 |
| 황혼의 마을 | 5 | 상점·대장장이·수집가 |
| 얼어붙은 산맥 | 7 | 생존·휴식 |
| 붉은 요괴성 | 8 | 정예·수호자·연속 전투 |
| 천공의 서고 | 7 | 학습·유물·희귀 보상 |

최종 분기는 보스 또는 잠긴 비밀 보스입니다. 정답 12개와 유물 2개 또는 동굴 지도 선택으로 비밀 경로를 엽니다. 동굴 이벤트에서는 별도의 비밀 전투로 바로 들어갈 수도 있습니다. 새 지도는 `world.version:2`; 기존 `world.version:1`의 6목적지 지도는 유지하고 다음 지역도 기존 형식으로 생성합니다.

이벤트 12종: 여행자, 샘물, 대장장이, 수상한 상인, 봉인 상자, 고대 제단, 무기고, 요괴 거래, 숲 정령, 잊힌 서고, 동굴, 장비 수집가. 각 3개 선택지에 비용/효과를 표시합니다. 요괴 저주는 해당 탐험에서 적 공격 +1이며 영구 장비와 혼합하지 않습니다.

### 4. 보스·연출·외형

보스 행동 예고에 포자 중독, 흡혈, 다음 드로우 감소, 서리 보호막, 화상, 강화 해제를 표시합니다. 체력 50%에서 2페이즈로 바뀝니다. 지역별 보스는 기존 3종 기본 실루엣에 잎·가면·등불·고드름·왕관·책장 장식을 추가했습니다.

무기는 지역별 검·얼음 창·화염검·별 지팡이 형태, 등급 발광, +10 강조를 사용합니다. 방어구는 지역 색상과 등급 장식을 반영합니다. 치명타·추가 공격·세트 효과·장비 회복을 피해 결과와 연출에 표시합니다. 노드/카드/학습의 한 턴 구조는 그대로입니다.

## 저장 호환과 복구

`kanacard-save-v4`의 단일 JSON에 run, gear, stats, collection, keepsake, growth를 함께 저장합니다. 탐험의 드롭 큐와 장비 프로필의 수령 키가 같은 저장본에 들어가므로 새로고침에 따른 중복 수령을 막습니다. 직전 저장본은 `kanacard-save-v4-backup`에 보관하며 기본 JSON을 읽지 못하면 백업을 읽습니다. 기존 localStorage 키는 최초 마이그레이션/읽기 호환과 미러로 유지합니다. 8층 version:2와 기존 6지역 version:3 모두 지원합니다.

새 장비 프로필의 items/equipped/claims/bossClaims/금화/재료/다음 ID를 정규화합니다. 중복 ID·잘못된 슬롯/등급·범위 밖 강화·잘못된 장착 참조를 제거하고 나머지를 살립니다. 새 ID는 기존 ID와 충돌하지 않을 때까지 증가합니다. 유물은 기존 run.relics에 남아 새 탐험에서는 초기화됩니다.

장비 보상은 run/node/wave 키와 적의 lootGranted 및 encounter.completed로 중복을 막습니다. 통합 저장을 쓰지 않던 진행 중인 탐험에는 run ID와 첫 보스 기록을 보완합니다. 이미 진행 중인 전투에 새 적을 추가하거나 경로를 재추첨하지 않습니다.

## 검증

- 1단계: 장착/해제/교체, 판매 보호, +10 비용, 세트, 정규화, 체력 중복, 오답 장비 공격 제외.
- 2단계: 보스 드롭 등급과 지역, 첫 보스/처치 키 중복 수령 방지, 재료, 옵션 저장.
- 3단계: 서로 다른 6개 지도 구조, 12이벤트 모든 선택지, 비밀 개방, 옛 지도 호환.
- 4단계: 6보스 예고/페이즈/장식, 중독·흡혈·혼란, 단일 적 유지. 캐릭터 장비 조합 30종과 보스 장식 6종의 SVG XML 구문 확인.
- 통합: 장비창/비교 UI, 통합 저장, 정답 확인 상태에서 새로고침, HP·드롭 중복 방지, 기존 학습/전투/월드/PWA/오디오 테스트.

## 남은 검증과 개선 후보

브라우저 제어 도구가 없어 실제 휴대폰의 렌더링·터치·장비 발광·오디오 청취는 미검증입니다. 데이터/규칙/DOM 문자열 검증이 실제 기기 QA를 대체하지 않습니다. 모든 캐릭터·오답률·장비 등급 조합의 장기 승률은 실제 플레이로 추가 조정해야 합니다. 같은 브라우저의 여러 탭에서 서로 다른 탐험을 동시에 진행하는 상태 병합은 제공하지 않습니다.

추가 개선은 장비 검색·즐겨찾기, 옵션별 정렬, 세트별 도감, 세로 화면 실제 기기 QA, 실제 승률에 따른 드롭/강화 비용 조정입니다.
