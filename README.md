# kanacard · 글자가 마법이 되는 모험

일본어 문제를 풀고 글자 마법으로 싸우는 모바일 읽기 액션 RPG입니다. 서버와 로그인 없이 GitHub Pages 또는 로컬에서 실행하며 PWA로 설치할 수 있습니다.

게임 주소: https://easthyeok.github.io/kanacard/

## 플레이

1. 가나 순간 읽기 / 단어 / 기본 표현 / 상황별 회화와 캐릭터를 선택합니다. 가나는 히라가나·가타카나·탁음·반탁음·요음 전체 208개 항목을 한 스테이지에서 섞어 출제합니다. 묶음 읽기는 자동(2글자부터) 또는 1·2·3·4·6글자 고정, 문제는 문자에서 발음을 고르는 방향입니다.
2. 지역 진입 후 지도의 밝은 목적지를 고릅니다. 연결된 경로만 이동할 수 있습니다.
3. 전투에 들어가면 전장과 선택지가 있는 읽기 문제를 같은 화면에 표시합니다. 문제 모달은 사용하지 않으며, 정답 공격·오답 반격 중에도 해당 글자와 선택지가 남아 있습니다. 정답은 즉시 공격하고 다음 문제로 이어지며, 빠른 정답은 추가 피해와 콤보를 얻습니다.
4. 오답·시간 초과는 공격 피해가 0입니다. 정답을 확인하고 계속하면 적이 한 번 반격합니다. 발음 도움을 쓰면 빠른 회상으로 기록되지 않습니다.
5. 승리 보상으로 체력 20% 회복 / 정답 공격 +2(누적 최대 +6) / 반격 방어 +1(누적 최대 +4) 중 하나를 선택합니다. 캐릭터·장비·유물을 성장시키며 여섯 지역의 보스를 물리칩니다.

자동 묶음은 최근 12문제 중 11개 이상 정답·8개 이상 빠른 정답이면 한 글자 길어지고, 정답이 8개 미만이면 한 글자 짧아집니다(1~6글자). 고정 길이도 선택할 수 있습니다. 오답과 느린 정답은 3문제를 더 푼 뒤 같은 묶음으로 복습합니다. 보스전에서는 약한 문자의 출제 비중이 높아집니다.

학습 단계와 월드는 별개입니다. 가나 순간 읽기를 선택해도 모든 지역을 탐험할 수 있습니다. 특정 문자/행에 따른 몬스터 약점은 없습니다. 가나 읽기는 표시 시점부터 제한시간을 적용합니다. 도전은 1.5초 + 항목당 0.5초(3글자 3초), 연습은 1.5배, 숙련은 0.75배입니다. 시간 초과는 오답이며 제한시간 70% 이내에 발음 도움 없이 맞혀야 빠른 회상으로 기록됩니다. 5회 연속 빠른 정답을 별도 집계하고, 느린 정답도 복습 대상으로 다시 출제합니다. 묶음 성적은 개별 문자 숙련의 참고치입니다. 단어·회화는 시간제한이 없고 오답 뒤에는 해설을 직접 확인합니다. 한글 발음은 읽기 보조이며 발음 듣기는 기기의 일본어 음성 합성 지원에 따릅니다.

## 월드와 경로

| 지역 | 테마 |
|---|---|
| 시작의 숲 | 숲·초원 |
| 안개 낀 신사 | 도리이·안개 |
| 황혼의 마을 | 등불·전통 골목 |
| 얼어붙은 산맥 | 설산·얼음 |
| 붉은 요괴성 | 성벽·화염 |
| 천공의 서고 | 별빛·책장 |

새 탐험의 지역은 각각 6·7·5·7·8·7개 목적지를 거칩니다. 기존 저장의 6개 목적지 지도는 유지합니다. 지도 배치·연결·이벤트·보상은 탐험마다 바뀌며 저장 후에도 같은 상태로 이어집니다.

- 일반/정예/보스 전투와 위험도 표시
- 생존: 적 처치 또는 4문제를 완료하면 승리
- 연속: 회복 없이 3연전, 마지막에 한 번 보상
- 보물 수호자: 강한 적과 장비 보상
- 상점: 회복약·유물·희귀 장비 구매
- 휴식: 최대 체력 30% 회복 또는 읽기 공격 +2(누적 최대 +6)
- 이벤트: 여행자·제단·샘물 선택에 따른 체력·금화·공격·유물 변화
- 보물: 금화와 유물
- 학습 도전: 기존 문제 3개, 정답마다 금화, 전부 정답이면 추가 보상

지역 보스는 고유 행동 순서와 체력 50% 이하 2페이즈가 있습니다. 보스 보상에서 장비와 유물을 얻고 다음 지역 진입 시 체력을 회복합니다.

## 읽기 전투와 성장

카드 선택·덱 구성·카드 도감은 플레이에서 제거했습니다. 기존 저장은 학습 기록·지역 진행·장비·금화·캐릭터 성장을 유지한 채 읽기 전투로 전환합니다. 과거 카드 데이터는 저장 호환을 위해 보존합니다.

기본 정답 피해는 18입니다. 빠른 정답은 피해 +6과 빠른 콤보당 +2(콤보 보너스 최대 +8)를 얻습니다. 느린 정답도 기본 공격을 하며, 빠른 콤보는 끊기고 복습 대상으로 남습니다. 5연속 정답마다 체력 2를 회복합니다. 실수에만 적이 반격하며 중독·화상·흡혈·서리·혼란·봉인 등의 지역 패턴을 유지합니다. 혼란은 다음 빠른 추가 피해를 봉인하고, 봉인은 빠른 콤보를 초기화합니다.

- 마법사: 정답 피해 +2
- 여우: 빠른 정답 피해 +2
- 마녀: 3연속 정답마다 체력 2 회복
- 기사: 반격 방어 +3

캐릭터 경험치·레벨과 장비는 영구 유지됩니다. 공격 강화와 유물은 탐험 한정입니다. 예전 카드 뽑기 유물은 빠른 정답 피해 +1로 바뀝니다.

## 영구 장비와 파밍

상단 ‘장비’에서 캐릭터별 무기·방어구·장신구를 장착합니다. 일반/고급/희귀/전설/신화 등급과 지역 세트가 있습니다. 인벤토리에서 정렬·등급 필터·비교·판매·분해를 지원하며 장비 골드와 재료로 +10까지 실패 없이 강화합니다. 전투 중에는 교체·강화할 수 없습니다.

몬스터·보스·보물·이벤트·상점에서 장비를 획득합니다. 첫 지역 보스 처치에는 전설 장비를 받고, 보스 전용 장비는 별도 이름과 기본 능력 보너스가 있습니다. 장비와 강화는 영구 보존되며 유물은 탐험에만 적용됩니다. 기존 탐험 금화와 영구 장비 골드는 서로 다른 재화입니다.

장비 공격·치명타·추가 공격은 정답 공격에서만 발동합니다. 읽기 전투에서 장비 공격은 최대 +5, 반격 방어는 +4, 정답 회복은 +1입니다. 치명타와 추가타는 빠른 정답일 때만 발동합니다. 과거 첫 턴 카드 옵션은 빠른 정답 피해 +1로, 천공 3세트는 3연속 정답 피해 +1로 바뀝니다. 오답으로는 장비 피해도 발생하지 않습니다. 무기 형태·발광과 방어구 색상은 전투 SVG에 반영됩니다.

이벤트는 12종으로 확대됐으며 동굴 지도, 정답 12개+유물 2개 조건으로 비밀 보스를 만날 수 있습니다. 여러 마리 전투는 사용자 요청에 따라 제외했고 한 번에 적 한 마리와 싸웁니다. 무한 탑과 문자 약점은 없습니다.

자세한 설계·변경 파일·저장 복구·단계별 검증은 [장비 확장 문서](docs/equipment-content.md)에 정리했습니다.

## 모바일과 PWA

전투에서는 전장과 문제가 함께 표시되며 선택지 터치 또는 숫자 키 1~8로 답합니다. 정답 후에는 짧은 공격 연출과 함께 다음 문제로 넘어가고, 오답은 정답을 확인한 뒤 계속합니다. 캐릭터는 작게 유지하고 전투는 현재 화면 높이를 사용합니다. 짧은 가로 화면은 전장 전체를 축소해 표시합니다. 회전과 주소창·노치 여백을 고려하며 퀴즈와 비전투 화면은 내부/문서 스크롤을 지원합니다.

Chrome 메뉴의 앱 설치 또는 홈 화면에 추가를 사용합니다. iOS는 Safari 공유 메뉴 → 홈 화면에 추가를 사용합니다. 방향은 고정하지 않습니다. 서비스 워커 설치 후 게임 코드와 문제·아이콘은 오프라인에서도 사용할 수 있습니다. 외부 글꼴·음성은 기기에 따라 다를 수 있습니다.

`BGM`은 기본 OFF이며 켜면 지역별 음계와 템포의 앰비언트 루프를 재생합니다. 탭이 숨겨지면 멈춥니다. 음성 문제 읽기와 별도로 설정합니다.

새 버전은 준비 화면의 업데이트 버튼으로 적용합니다. 오래된 화면이 계속 보이면 https://easthyeok.github.io/kanacard/recover.html 에서 최신 버전을 받습니다. 캐시 복구는 저장 데이터를 지우지 않습니다.

## 저장 호환성

기존 `version:2`의 8층 탐험은 그대로 끝까지 이어갈 수 있습니다. 새 탐험부터 `version:3`의 6지역 탐험이 적용됩니다. 기존 학습 진도·난이도·캐릭터 경험치·도감·진행 중인 질문과 해설을 유지합니다. 새 탐험으로 교체할 때는 기존 확인 화면이 나옵니다.

`kanacard-save-v4` 통합 저장본과 직전 백업에 장비·탐험·학습 데이터를 함께 기록합니다. 기존 키도 읽기 호환으로 유지합니다. localStorage에 자동 저장하며 기기 간 동기화는 없습니다. 사이트 데이터를 삭제하면 저장도 지워집니다. 상세 스키마와 호환성 정책은 [스테이지 시스템 문서](docs/stage-system.md)를 참고하세요.

## 로컬 실행과 테스트

```sh
python3 -m http.server 8000
```

http://localhost:8000/ 에서 플레이합니다. `index.html` 직접 열기도 가능하지만 설치·서비스 워커는 HTTPS 또는 localhost가 필요합니다.

```sh
node tests/game.cjs
node tests/app.cjs
node tests/reading.cjs
node tests/world.cjs
node tests/word-effects.cjs
node tests/pwa.cjs
node tests/music.cjs
node tests/gear.cjs
node tests/rpg-content.cjs
```

추가 패키지 없이 Node.js 22로 테스트합니다. 실제 휴대폰 렌더링·설치·오디오 청취 검증은 배포 후 필요합니다.

## 구성과 배포

- `gear-config.js`, `gear.js`, `gear-view.js`: 장비 설정·영구 규칙·모바일 UI
- `content-config.js`: 지역별 지도·12이벤트·숨겨진 보스·특수 패턴
- `world-config.js`: 카드·적·보상·상점·특수 전투 수치, 지역·유물·노드 설정
- `reading-combat.js`: 읽기 공격·빠른 콤보·반격·자동 길이·복습·저장 전환
- `core.js`: 기존 전투와 8층 호환 규칙, 새 월드 연결 지점
- `world.js`: 분기·특수 전투·보상·상점·강화·저장 검증
- `world-view.js`, `world-art.js`, `music.js`: 월드 UI, 지역 배경, 배경음
- `app.js`, `lessons.js`: 화면/학습/저장 연결과 기존 학습 데이터

저장소 https://github.com/easthyeok/kanacard 의 Settings → Pages → Source를 GitHub Actions로 설정합니다. main에 push하면 테스트 후 정적 파일만 배포합니다. 변경된 오프라인 자산을 배포할 때 `sw.js`의 캐시 버전도 올려주세요.

```sh
git push origin main
```

## 문자 숙련

기존 저장 번호는 유지하고, 문자 학습은 가나 순간 읽기 하나로 합쳤습니다. 기본 46개와 탁음·반탁음·요음 58개를 두 문자 체계로 출제합니다. 2개 이상인 일반 묶음은 히라가나·가타카나를 함께 포함하며, 복습 묶음은 틀렸거나 느렸던 원래 조합을 유지합니다.

연습은 4지선다, 도전은 6지선다와 적 능력 1.2배, 숙련은 8지선다와 적 능력 1.45배입니다. 모두 글자를 보고 읽는 방향이며, 오답 피해는 0입니다. 기본 선택은 도전이며 기존 탐험은 기존 난이도를 유지합니다.

각 문자의 정답·오답·연속 빠른 정답 기록을 영구 저장합니다. 빠른 정답 5회 연속을 숙련 참고치로 표시합니다. 묶음 전체의 결과이므로 개별 문자의 완전 습득을 뜻하지 않습니다. 느리거나 틀린 문자는 지연 복습에 더해 일반 문제에도 우선 등장하고, 보스전은 그 비중이 높아집니다. 쓰기·촉음·장음·실제 문장 읽기는 별도 연습이 필요합니다. 한글 표기는 근사 발음입니다.

정답은 짧은 시각 공격 연출로 바로 이어집니다. 발음 듣기 버튼과 오답 복습 음성으로 소리를 확인할 수 있습니다. 다음 문제가 열리면 이전 음성을 멈춰 제한시간 동안 겹치지 않게 합니다. 일본어 음성 지원은 기기에 따라 다릅니다.
