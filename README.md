# kanacard · 카나카드

글자가 마법이 되는 일본어 학습 턴제 카드 게임입니다. 설치나 로그인 없이 `index.html`을 열어 플레이합니다.

## 게임 방법

1. 히라가나 / 가타카나 / 기초 단어 / 기본 표현 / 상황별 회화 중 학습 단계를 고릅니다.
2. 네 캐릭터 중 하나를 골라 탐험을 시작합니다.
3. 지도에서 전투, 엘리트, 모닥불, 이벤트를 선택하며 8층까지 올라갑니다.
4. 전투에서 카드를 선택하고 일본어 문제에 답합니다. 정답이면 온전한 효과, 오답이면 피해·방어·회복이 절반으로 적용됩니다. 뽑기 카드는 오답 시 한 장 적게 뽑고, 약화는 정답일 때 적용됩니다.
5. 에너지와 적의 다음 행동을 살피고 턴을 종료합니다. 다음 턴에는 에너지가 회복되고 카드가 새로 들어옵니다. 방어도는 매 턴 초기화됩니다.
6. 승리 후 카드 3장 중 하나를 덱에 추가하거나 보상을 건너뜁니다. 8층의 망각의 사서를 물리치면 완료입니다.

시간제한이 없습니다. 오답 뒤에는 정답과 해설을 확인하고 직접 계속 진행합니다. 소멸 카드는 해당 전투에서만 제외되며, 다음 전투에서 다시 사용할 수 있습니다.

## 캐릭터

- 숲의 마법사: 체력 60, 정답 공격 피해 +2
- 여우 길잡이: 체력 54, 매 전투 첫 턴 에너지 +1
- 달빛 마녀: 체력 52, 매 턴 카드 1장 추가로 뽑기
- 잉크 기사: 체력 70, 매 턴 방어도 2로 시작

## 학습과 저장

문자 단계는 5 / 15 / 46자 범위와 2 / 3 / 4글자 묶음 읽기를 지원합니다. 기본은 46자, 3글자입니다. 모든 문자를 한 번씩 섞어 출제한 뒤 다시 섞습니다. 문자 조합은 단어가 아니며, 문자 읽기는 nu 대신 누처럼 한글 발음으로 선택합니다. 「お／を」는 모두 오로 표시하며, 한글 표기는 읽기 보조이므로 일본어 음성도 함께 들어보세요.

회화는 상황별 4지선다 연습입니다. 자유 대화나 발음 평가는 포함하지 않습니다. 발음 듣기는 기기의 일본어 음성 합성 지원에 따라 다릅니다.

탐험은 행동마다 브라우저 localStorage에 자동 저장됩니다. 상단 로고로 설정으로 돌아온 뒤 ‘저장한 탐험 계속’을 누르거나, 브라우저를 다시 열어 이어할 수 있습니다. 퀴즈와 정답 확인 화면도 복원합니다. 새 탐험으로 교체할 때는 확인 화면이 표시됩니다. 이전 버전의 누적 탐험·정답 기록은 유지합니다. 기기 간 동기화는 없습니다.

PC: 카드 선택 1–9, 정답 선택 1–4, 턴 종료 E, 정답 확인 후 Enter, 퀴즈 취소 및 덱 닫기 Esc. 모바일에서는 버튼을 터치하고 카드 목록을 좌우로 스크롤합니다.

## 로컬 실행과 검증

`index.html`을 직접 열거나 이 폴더에서 실행합니다.

```sh
python3 -m http.server 8000
```

http://localhost:8000 에 접속합니다. 같은 네트워크의 휴대폰에서는 PC IP와 포트로 접속할 수 있습니다. 외부 폰트가 로드되지 않아도 기본 글꼴로 작동합니다.

Node.js로 전투 규칙과 화면 연결 테스트를 실행합니다. 추가 패키지가 필요하지 않습니다.

```sh
node tests/game.cjs
node tests/app.cjs
```

## GitHub Pages 배포

저장소: https://github.com/easthyeok/kanacard

저장소 Settings → Pages에서 Source를 **GitHub Actions**로 선택합니다. 프로젝트 루트의 파일과 `.github/workflows/pages.yml`을 main 브랜치에 push하면 테스트 후 정적 파일만 배포합니다. 성공 시 접속 주소는 https://easthyeok.github.io/kanacard/ 입니다.

이 환경에서 원격 업로드가 불가능한 경우, 네트워크가 되는 터미널에서 이 폴더를 열고 아래 순서로 실행하세요. GitHub 인증이 필요할 수 있습니다.

```sh
git add .
git commit -m "Launch kanacard"
git push -u origin main
```

원격 main에 README 등 기존 커밋이 있으면 push가 거절될 수 있습니다. 먼저 `git fetch origin`과 `git merge origin/main --allow-unrelated-histories`로 기존 파일을 합친 뒤 push하세요. 강제 push는 하지 않습니다.


## 전투 연출

정답 확인 후 계속하기를 누르면 카드 효과가 전장에 나타납니다. 공격 궤적과 타격 파편, 불꽃·얼음, 방어막·회복·카드 뽑기 효과, 피해 숫자, 연속 정답 표시를 지원합니다. 적의 반격과 처치에도 별도 연출이 있으며, 약 0.9초의 연출 중에는 중복 행동을 막습니다. 기기의 동작 줄이기 설정을 켜면 움직임 대신 결과 표시를 유지합니다.

## 영구 성장과 강화된 이펙트

캐릭터별 경험치와 레벨이 브라우저에 저장됩니다. 정답 +10, 오답 +2 경험치이며, 적 처치 시 일반 +20 / 엘리트 +40 / 보스 +80을 추가로 받습니다. 패배와 새 탐험으로 초기화되지 않습니다. 첫 레벨업에는 경험치 60이 필요하고 이후 필요량은 레벨마다 20씩 증가합니다.

레벨마다 최대 체력 +2, 3레벨 상승마다 공격 +1, 4레벨 상승마다 매 턴 방어 +1이 누적됩니다. 성장 보너스는 새 탐험을 시작할 때 반영되므로 진행 중인 탐험의 능력치는 유지됩니다. Lv.3에는 작은 번뜩임, Lv.6에는 불꽃 문장을 시작 덱에 추가합니다. 설정 화면에서 선택한 캐릭터의 레벨과 다음 탐험 보너스를 확인할 수 있습니다. 기존 탐험과 학습 기록도 계속 사용할 수 있습니다.

연속 참격, 속성별 파편, 충격파와 처치 폭발을 추가했습니다. 3회 이상 연속 정답과 처치 시 강조 연출을 사용합니다. 동작 줄이기 설정에서는 섬광과 화면 흔들림을 끕니다.

공격 모션은 준비 자세 → 적 앞까지 돌진 → 약 80ms 접촉 정지 → 반동과 복귀 순서입니다. 실제 화면의 캐릭터·적 좌표로 돌진 거리와 타격 위치를 맞춥니다. 공격 자세에서 팔·다리와 무기 방향이 바뀌며, 명중 시점에 적 밀림·참격 곡선·피해 숫자·화면 흔들림이 함께 시작됩니다. 동작 줄이기를 사용하면 돌진과 자세 전환도 생략합니다.

## 카드 수집

카드는 총 15종이며 일반·고급·희귀와 15가지 시각 테마를 사용합니다. 번개·가시·별·달·꽃·메아리 카드가 추가되었습니다. 희귀도는 현재 카드 분류와 외형 표시이며 보상 확률에 가중치를 주지는 않습니다.

상단 ‘카드 도감’ 또는 준비 화면에서 수집 상태와 희귀도별 목록을 봅니다. 기본 3종과 기존 저장 덱은 자동으로 도감에 등록되고, 보상에서 실제 획득한 카드도 영구 저장됩니다. 미수집 보상에는 NEW가 표시됩니다. 도감에서 수집한 보상 카드 하나를 시작 카드로 선택하면 다음 새 탐험에서 기본 공격 한 장을 교체합니다. 진행 중인 덱은 바뀌지 않습니다. 선택 해제로 기본 구성을 복원할 수 있습니다. 도감은 같은 브라우저에 저장됩니다.

전투 캐릭터는 `combat-actor.js`의 관절별 SVG로 표시합니다. 상체 회전, 어깨의 무기 휘두르기, 손목 스냅, 다리 디딤, 머리와 망토 반동을 각각 움직입니다. `motion-preview.html`에서 퀴즈 없이 네 캐릭터의 공격 모션을 반복 확인할 수 있습니다.

## 모바일 전투 화면

전투 중 학습 단계 메뉴를 접고 화면 높이에 맞춰 전장·조작 버튼·손패를 배치합니다. 세로 모바일에서는 손패를 좌우로 밀어 선택하며, 가로 화면에는 낮은 카드와 작은 캐릭터 배치를 적용합니다. 노치·홈 표시줄 여백과 브라우저 주소창 높이 변화를 고려합니다. 주요 조작 버튼은 최소 44px 이상이며, 확대 제스처는 유지합니다. 실제 휴대폰 브라우저 검증은 별도로 필요합니다.

## PWA 앱 설치와 오프라인

`futari`의 설치·업데이트 방식을 참고했습니다. HTTPS 배포 후 Chrome에서 ‘앱 설치’ 버튼 또는 브라우저 메뉴의 ‘앱 설치/홈 화면에 추가’를 사용합니다. iPhone/iPad는 Safari 공유 메뉴 → 홈 화면에 추가를 사용합니다. 설치 후 주소창 없이 독립 앱으로 실행합니다. 학습 문제와 선택지를 읽기 편한 세로 사용을 권장합니다. 화면 방향은 강제하지 않아 기기를 회전하면 가로 전투도 지원합니다.

서비스 워커 설치가 완료된 뒤에는 게임 코드·아이콘·문제를 오프라인으로 사용할 수 있습니다. 외부 글꼴과 음성은 기기 지원·캐시에 따라 달라집니다. 진행과 도감은 기존 localStorage를 그대로 사용합니다. 앱 삭제·사이트 데이터 삭제 시 저장 데이터가 사라질 수 있습니다.

새 버전은 자동으로 전투 중 새로고침하지 않습니다. 준비 화면에서 ‘업데이트’를 누르면 전환하며, 문제 풀이·정답 확인·전투 연출 중에는 업데이트를 막습니다. 앱 코드 수정 시 `sw.js`의 캐시 버전을 함께 올려야 합니다. 캐시는 이 앱의 경로만 관리하므로 같은 도메인의 futari 캐시는 건드리지 않습니다.

가로 전투 화면은 최소 높이 고정을 제거하고 주소창이 차지한 실제 높이(`visualViewport`), 노치, 하단 여백에서 손패·버튼 공간을 뺀 값으로 캐릭터 크기를 결정합니다. 매우 짧은 화면에서는 카드 삽화를 줄이고 손패를 가로 스크롤합니다. 퀴즈창은 내부 스크롤로 모든 선택지와 계속 버튼에 접근할 수 있습니다.

추가 검증: `node tests/pwa.cjs`. 실제 Chrome 설치 및 휴대폰 가로 화면 검증은 배포 후 필요합니다.

적의 행동 표시는 캐릭터 영역 안에서 별도 높이를 확보합니다. 가로 화면에서는 전장 내 캐릭터 영역과 손패·버튼 영역을 분리하여 행동 표시가 전장 위로 잘리지 않도록 합니다.

## 예전 화면이 계속 보일 때

https://easthyeok.github.io/kanacard/recover.html 에서 최신 버전 받기를 누릅니다. 해당 앱 경로의 서비스 워커와 캐시만 제거하며 localStorage의 저장 데이터는 삭제하지 않습니다. 가로 잠금이 남은 기존 설치 앱은 Chrome에서 직접 열어 세로를 확인한 뒤 필요하면 재설치합니다. 기기의 자동 회전을 켜주세요.

짧은 가로 화면에서는 높이 480 기준의 전투 화면 전체를 남은 화면 높이에 맞춰 축소합니다. 전장·손패·조작 버튼이 함께 축소되고, 글자 발사의 좌표도 같은 비율로 보정됩니다.

세로 모바일은 전투 높이 최대 620px, 캐릭터 128px, 손패 영역 166px로 더 작게 표시합니다. 가로 배치는 유지합니다. 전투 알림은 2.5초 뒤 사라지고, 문제·정답 확인 창이 열리면 제거되어 글자를 가리지 않습니다. 설치 manifest의 방향 설정도 제거했습니다. 과거 가로 고정 버전으로 설치된 Android 앱은 최신 배포 후 재설치가 필요할 수 있습니다. 재설치 전 Chrome에서 저장 탐험이 보이는지 확인하고, 제거 과정에서 사이트 데이터 삭제는 선택하지 마세요.
