# kanacard · 글자가 마법이 되는 모험

일본어 문제를 풀고 글자 마법으로 싸우는 모바일 읽기 액션 RPG입니다. 서버와 로그인 없이 GitHub Pages 또는 로컬에서 실행하며 PWA로 설치할 수 있습니다.

게임 주소: https://easthyeok.github.io/kanacard/

## 플레이

1. 가나 순간 읽기 / 단어 / 기본 표현 / 상황별 회화를 선택합니다. 캐릭터는 잿빛 전사 하나로 고정하며 선택 화면은 없습니다. 가나는 히라가나·가타카나·탁음·반탁음·요음 전체 208개 항목을 한 스테이지에서 섞어 출제합니다. 묶음 읽기는 자동(2글자부터) 또는 1·2·3·4·6글자 고정, 문제는 문자에서 발음을 고르는 방향입니다.
2. 지역 진입 후 지도의 밝은 목적지를 고릅니다. 연결된 경로만 이동할 수 있습니다.
3. 전투에 들어가면 전장과 선택지가 있는 읽기 문제를 같은 화면에 표시합니다. 문제 모달은 사용하지 않으며, 정답 공격·오답 반격 중에도 해당 글자와 선택지가 남아 있습니다. 정답은 즉시 공격하고 다음 문제로 이어지며, 빠른 정답은 추가 피해와 콤보를 얻습니다.
4. 오답·시간 초과는 공격 피해가 0입니다. 정답을 확인하고 계속하면 적이 한 번 반격합니다. 발음 도움을 쓰면 빠른 회상으로 기록되지 않습니다.
5. 승리 보상으로 체력 20% 회복 / 정답 공격 +2(누적 최대 +6) / 반격 방어 +1(누적 최대 +4) 중 하나를 선택합니다. 캐릭터·장비·유물을 성장시키며 여섯 지역의 보스를 물리칩니다.

자동 묶음은 최근 12문제 중 11개 이상 정답·8개 이상 빠른 정답이면 한 글자 길어지고, 정답이 8개 미만이면 한 글자 짧아집니다(1~6글자). 고정 길이도 선택할 수 있습니다. 오답과 느린 정답은 3문제를 더 푼 뒤 같은 묶음으로 복습합니다. 묶음 오답은 이후 한 글자씩도 확인하며, 확인 문제는 자동 묶음 길이 조절의 성적에서 제외합니다. 보스전에서는 약한 문자의 출제 비중이 높아집니다.

오답에서 선택한 보기의 문자도 함께 기록해 `シ ↔ ツ`, `ソ ↔ ン`처럼 실제로 혼동한 쌍을 모읍니다. 한 위치만 바뀐 보기를 선택했을 때 기록하며, 시간 초과와 문자 정보가 없는 예전 문제는 제외합니다. 혼동 빈도와 최근 기록에 따라 한 글자씩 양방향으로 복습하고, 상대 글자의 발음을 반드시 보기에 넣습니다. 혼동 쌍 복습은 자동 묶음 길이 조절 성적에서 제외하며, 5회 연속 빠른 정답이면 집중 출제를 마치고 다시 틀리면 재개합니다. 시작 화면에서 혼동 쌍과 누적 횟수를 확인할 수 있으며, 기록은 탐험을 바꾸거나 새로고침해도 유지됩니다.

학습 단계와 월드는 별개입니다. 가나 순간 읽기를 선택해도 모든 지역을 탐험할 수 있습니다. 특정 문자/행에 따른 몬스터 약점은 없습니다. 가나 읽기는 표시 시점부터 제한시간을 적용합니다. 도전의 응답 제한은 2초 + 항목당 1초(3글자 5초)이고, 빠른 회상 목표는 별도로 1.5초 + 항목당 0.5초(3글자 3초)입니다. 연습은 두 시간 모두 1.5배, 숙련은 0.75배입니다. 제한시간 안에 맞히면 정답이며, 빠른 회상 목표 안에 발음 도움 없이 맞히면 보너스를 얻습니다. 저장된 진행 중 문제도 시작 시점을 유지하면서 새 시간 기준을 적용합니다. 5회 연속 빠른 정답을 별도 집계하고, 느린 정답도 복습 대상으로 다시 출제합니다. 묶음 성적은 개별 문자 숙련의 참고치입니다. 단어·회화는 시간제한이 없고 오답 뒤에는 해설을 직접 확인합니다. 한글 발음은 읽기 보조이며 발음 듣기는 기기의 일본어 음성 합성 지원에 따릅니다.

## 월드와 경로

| 지역 | 테마 |
|---|---|
| 시작의 숲 | 숲·초원 |
| 안개 낀 신사 | 도리이·안개 |
| 황혼의 마을 | 등불·전통 골목 |
| 얼어붙은 산맥 | 설산·얼음 |
| 붉은 요괴성 | 성벽·화염 |
| 천공의 서고 | 별빛·책장 |

새 탐험의 지역은 각각 6·7·5·7·8·7개 목적지를 거칩니다. 기존 저장의 6개 목적지 지도는 유지합니다. 지도 배치·연결·이벤트·보상은 탐험마다 바뀌며 저장 후에도 같은 상태로 이어집니다.

- 일반/정예/보스 전투와 위험도 표시
- 생존: 적 처치 또는 4문제를 완료하면 승리
- 연속: 회복 없이 3연전, 마지막에 한 번 보상
- 보물 수호자: 강한 적과 장비 보상
- 상점: 회복약·유물·희귀 장비 구매
- 휴식: 최대 체력 30% 회복 또는 읽기 공격 +2(누적 최대 +6)
- 이벤트: 여행자·제단·샘물 선택에 따른 체력·금화·공격·유물 변화
- 보물: 금화와 유물
- 학습 도전: 기존 문제 3개, 정답마다 금화, 전부 정답이면 추가 보상

지역 보스는 고유 행동 순서와 체력 50% 이하 2페이즈가 있습니다. 보스 보상에서 장비와 유물을 얻고 다음 지역 진입 시 체력을 회복합니다.

## 읽기 전투와 성장

이번 전사 업데이트는 캐릭터 경험치와 장착 상태를 한 번 초기화합니다. 진행 중 탐험은 체력 60·레벨 1의 전사로 바뀌며 공격·방어 강화와 유물·축복도 초기화합니다. 학습 기록·보유 장비·지역 진행·재화는 유지합니다. 초기화 버전을 학습 통계와 함께 원자적으로 저장하므로 이후 새로고침에서는 초기화하지 않습니다. 검·금속 갑옷·붉은 망토는 기존 SVG 애니메이션 관절로 그립니다.

카드 선택·덱 구성·카드 도감은 플레이에서 제거했습니다. 기존 저장은 학습 기록·지역 진행·장비·금화·캐릭터 성장을 유지한 채 읽기 전투로 전환합니다. 과거 카드 데이터는 저장 호환을 위해 보존합니다.

기본 정답 피해는 18입니다. 빠른 정답은 피해 +6과 빠른 콤보당 +2(콤보 보너스 최대 +8)를 얻습니다. 느린 정답도 기본 공격을 하며, 빠른 콤보는 끊기고 복습 대상으로 남습니다. 5연속 빠른 정답마다 체력 2를 회복하고 장비 회복 보너스는 최대 +1입니다. 한 전투의 정답 회복은 합계 6으로 제한하며 느린 정답은 회복하지 않습니다. 실수에만 적이 반격합니다. 방어·피해 감소는 원래 반격의 60%까지만 줄일 수 있고, 실수 피해에는 최대 체력의 8% 하한이 있습니다. 연속 실수마다 하한이 3%p씩 올라 최대 20%가 되며, 정답을 맞히면 연속 실수는 초기화됩니다. 반격 피해 하한 덕분에 고레벨·장비가 있어도 연속 오답만으로 버틸 수 없습니다.  중독·화상·흡혈·서리·혼란·봉인 등의 지역 패턴을 유지합니다. 혼란은 다음 빠른 추가 피해를 봉인하고, 봉인은 빠른 콤보를 초기화합니다.

잿빛 전사는 정답 피해 +2를 얻습니다. 새 탐험은 전사 하나로 고정합니다. 최초 초기화 이후 쌓은 경험치와 장착 상태는 계속 유지합니다.

캐릭터 경험치·레벨과 장비는 영구 유지됩니다. 공격 강화와 유물은 탐험 한정입니다. 예전 카드 뽑기 유물은 빠른 정답 피해 +1로 바뀝니다.

## 영구 장비와 파밍

상단 ‘장비’에서 캐릭터별 무기·방어구·장신구를 장착합니다. 일반/고급/희귀/전설/신화 등급과 지역 세트가 있습니다. 인벤토리에서 정렬·등급 필터·비교·판매·분해를 지원하며 장비 골드와 재료로 +10까지 실패 없이 강화합니다. 전투 중에는 교체·강화할 수 없습니다.

몬스터·보스·보물·이벤트·상점에서 장비를 획득합니다. 첫 지역 보스 처치에는 전설 장비를 받고, 보스 전용 장비는 별도 이름과 기본 능력 보너스가 있습니다. 장비와 강화는 영구 보존되며 유물은 탐험에만 적용됩니다. 기존 탐험 금화와 영구 장비 골드는 서로 다른 재화입니다.

장비 외형은 지역별로 달라집니다. 무기는 잎새 검·수호 도끼·초승 곡도·수정 창·화산 전투망치·별의 지팡이 6종이며, 보스 전리품은 포자 대검·쌍날 도끼·낫·삼지창·용아 대검·천체 지팡이로 바뀝니다. 방어구도 가죽갑·무사 도복·판금갑·수정갑·요괴갑·로브마다 투구·어깨·몸통·망토의 형태가 달라지고, 보스 갑옷에는 뿔과 날개 장식이 붙습니다. 장신구는 잎새·인장·달·수정·용의 눈·별 형태입니다. 희귀 등급부터 무기 보석, 전설 등급부터 금빛 갑옷 장식, +5부터 각성 문양, +10에 빛나는 장식이 추가됩니다. 기존 장비에도 바로 적용되며 강화·저장·불러오기 후에도 종류가 유지됩니다. [장비 외형과 공격 모션 미리보기](motion-preview.html)에서 12개 세트를 골라 등급·강화별 외형과 공격을 확인할 수 있습니다.

장비 화면은 전사의 현재 외형과 무기·갑옷·장신구 아이콘을 표시합니다. 슬롯별 필터로 장비를 찾고, 상세 화면에서 현재 모습과 장착 후 모습을 나란히 비교할 수 있습니다. 장착 중인 장비는 테두리로 강조합니다. 장비 공격·치명타·추가 공격은 정답 공격에서만 발동합니다. 읽기 전투에서 장비 공격은 최대 +5, 반격 방어는 +4, 5연속 빠른 정답 회복 보너스는 최대 +1입니다. 치명타와 추가타는 빠른 정답일 때만 발동합니다. 과거 첫 턴 카드 옵션은 빠른 정답 피해 +1로, 천공 3세트는 3연속 정답 피해 +1로 바뀝니다. 오답으로는 장비 피해도 발생하지 않습니다. 무기 형태·발광과 방어구 색상은 전투 SVG에 반영됩니다.

이벤트는 12종으로 확대됐으며 동굴 지도, 정답 12개+유물 2개 조건으로 비밀 보스를 만날 수 있습니다. 여러 마리 전투는 사용자 요청에 따라 제외했고 한 번에 적 한 마리와 싸웁니다. 무한 탑과 문자 약점은 없습니다.

자세한 설계·변경 파일·저장 복구·단계별 검증은 [장비 확장 문서](docs/equipment-content.md)에 정리했습니다.

## 모바일과 PWA

전투에서는 전장과 문제가 함께 표시되며 선택지 터치 또는 숫자 키 1~4로 답합니다. 정답 후에는 짧은 공격 연출과 함께 다음 문제로 넘어가고, 오답은 정답을 확인한 뒤 계속합니다. 캐릭터는 작게 유지하고 전투는 현재 화면 높이를 사용합니다. 세로 화면은 전장의 좌우에 캐릭터와 몬스터를 배치하고 가운데에 이동·공격 공간을 둡니다. 가로 화면은 전장과 문제를 좌우로 배치합니다. 회전과 주소창·노치 여백을 고려하며 퀴즈와 비전투 화면은 내부/문서 스크롤을 지원합니다.

Chrome 메뉴의 앱 설치 또는 홈 화면에 추가를 사용합니다. iOS는 Safari 공유 메뉴 → 홈 화면에 추가를 사용합니다. 방향은 고정하지 않습니다. 서비스 워커 설치 후 게임 코드와 문제·아이콘은 오프라인에서도 사용할 수 있습니다. 외부 글꼴·음성은 기기에 따라 다를 수 있습니다.

`BGM`은 기본 OFF이며 켜면 지역별 음계와 템포의 앰비언트 루프를 재생합니다. 탭이 숨겨지면 멈춥니다. 음성 문제 읽기와 별도로 설정합니다.

새 버전은 준비 화면의 업데이트 버튼으로 적용합니다. 오래된 화면이 계속 보이면 https://easthyeok.github.io/kanacard/recover.html 에서 최신 버전을 받습니다. 캐시 복구는 저장 데이터를 지우지 않습니다.

## 저장 호환성

기존 `version:2`의 8층 탐험은 그대로 끝까지 이어갈 수 있습니다. 새 탐험부터 `version:3`의 6지역 탐험이 적용됩니다. 기존 학습 진도·난이도·캐릭터 경험치·도감·진행 중인 질문과 해설을 유지합니다. 새 탐험으로 교체할 때는 기존 확인 화면이 나옵니다.

`kanacard-save-v4` 통합 저장본과 직전 백업에 장비·탐험·학습 데이터를 함께 기록합니다. 기존 키도 읽기 호환으로 유지합니다. localStorage에 자동 저장하며 기기 간 동기화는 없습니다. 사이트 데이터를 삭제하면 저장도 지워집니다. 상세 스키마와 호환성 정책은 [스테이지 시스템 문서](docs/stage-system.md)를 참고하세요.

## 문자 숙련

기존 저장 번호는 유지하고, 문자 학습은 가나 순간 읽기 하나로 합쳤습니다. 기본 46개와 탁음·반탁음·요음 58개를 두 문자 체계로 출제합니다. 2개 이상인 일반 묶음은 히라가나·가타카나를 함께 포함하며, 복습 묶음은 틀렸거나 느렸던 원래 조합을 유지합니다.

모든 난이도는 4지선다로 고정합니다. 도전은 적 능력 1.2배, 숙련은 1.45배이며 제한시간도 달라집니다. 기존 저장에 남은 6·8지선다 문제도 정답과 제한시간을 유지한 채 4지선다로 줄입니다. 모두 글자를 보고 읽는 방향이며, 오답 피해는 0입니다. 기본 선택은 도전이며 기존 탐험은 기존 난이도를 유지합니다.

각 문자의 정답·오답·연속 빠른 정답 기록을 영구 저장합니다. 빠른 정답 5회 연속을 숙련 참고치로 표시합니다. 묶음 전체의 결과이므로 개별 문자의 완전 습득을 뜻하지 않습니다. 틀린 횟수·최근 오답·느린 응답을 함께 반영해 우선 출제할 글자를 가중 추첨합니다. 빠른 연속 정답이 늘면 우선순위가 내려가며, 5회 빠른 연속 정답에 도달하면 일반 출제로 돌아갑니다. 묶음 오답은 개별 글자의 확정 오답과 구분하고, 3문제 뒤부터 한 글자 확인 문제를 간격을 두고 출제합니다. 확인 결과와 대기 목록은 학습 통계에 저장되어 새 탐험과 다음 접속에도 이어집니다. 복습은 최대 두 문제 연속까지만 출제하고 그다음에는 전체 문자에서 일반 문제를 냅니다. 일반 전투의 약점 가중 추첨 기회는 45%, 보스는 70%이며, 지연 복습·한 글자 확인도 같은 연속 제한을 따릅니다. 쓰기·촉음·장음·실제 문장 읽기는 별도 연습이 필요합니다. 한글 표기는 근사 발음입니다.

정답은 짧은 시각 공격 연출로 바로 이어집니다. 발음 듣기 버튼과 오답 복습 음성으로 소리를 확인할 수 있습니다. 다음 문제가 열리면 이전 음성을 멈춰 제한시간 동안 겹치지 않게 합니다. 일본어 음성 지원은 기기에 따라 다릅니다.
